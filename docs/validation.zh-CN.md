## 0.1.7rc1功能验收范围

以用户已接受的0.1.6rc2为回归基线。新增`configure-cable`、类别来源与确定性自动/目标段长/显式段数、Schema1.6及资源预算；旧包保存与导出不重选N。相关测试覆盖真实CAD尺寸、来源优先/0/false、模式冲突、超旧512、预算提前拒绝、解析记录不受后续预设更新影响、双快照一致性和定性编辑保留用户配置。

端到端验收须实际安装新payload/runtime，使用正式CLI保存、结束前一进程、独立USD导出/重开，验证有限原生初始化/短时结构与实际质量惯量。软件、预算和短时运行分别记状态，不把成功导出当理论精度通过。两项需要外部CAD-FEM fixture的既有跳过不补写为通过。完整日志/配置/原始结果保存在当轮独立结果目录，不覆盖下面历史。

高步频精细对照不作为普通资产默认；原480Hz失准证据及严格瞬时静态失败继续保留。类别EI/GJ、阻尼和接触初值未实物标定，自动N不是通用最优推荐。功能可作为带明确限制的候选交付，不能由第一阶段全部精度门槛未通过推导本轮功能也一概失败。

最小验收：descriptor/skill登记与runtime.check → 合同测试含jsonschema不跳过 → 新建简单CAD → inspect/template或声明 → enrich/set-rigid-chain保存 → 独立read/validate/expect及非物理语义保留 → 配套USD导出/重开 → 原生PhysX行为。前一层通过不代表后一层。

test_rigid_chain.py覆盖1.4声明、身份、单位/来源、0/false、未实现策略拒绝、端点、重复绑定、ground、刚体/FEM显式转换和JSON Schema。图/BREP stub是软件边界测试，不是物理标定。test_package_roundtrip.py以两个小型真实SCA fixture验证旧机械合同及rigid_joint_chain CLI补包、CAD绑定和完整保存回读。test_cad_deformable.py需--package才执行两项真实FEM用例，跳过必须说明。

V6完整演示要从项目CAD源码重新capture/中心线，使用当前physics声明1.4，再由当前USD生成链，不调用旧builder/读取旧USD作为生成输入。轨迹/native runner/分析留项目。除52段回归还需不同ID/长度/半径/N/端点圆线、单因素EI/GJ软硬、分段趋势、m/cm单位对照。per_joint c变N会改变等效耗散，不能称物理阻尼不变收敛。CCD接触样本不能证明全局无穿透。

旧verify_postattach/verify_mechanical_pipeline/Isaac探针保留为历史或项目集成工具，其旧项目输入不是最小验收隐式依赖。独立成果由每轮新结果目录保存，本说明不提前声明未来实测通过。

## 历史0.1.6rc1动态验收结果与未通过项

从保留建模源码重新生成CAD和中心线，经新插件正式入口保存/回读/直接导出刚体链后，V6的5秒/2400步测试通过，独立原生数组分析也通过：最大关节间隙0.426985毫米，端部间隙0.0377494毫米，最大长度增量0.622581%。它证明该V6场景回归可运行，不能扩展为所有线缆的定量精度证明。

不同尺寸/路径/端部的通用案例通过结构稳定检查，恒载下增加EI或GJ可减小相应变形的定性软硬对照也通过。**定量验收没有通过**：保持质量0.01kg、材料长度0.25m及EI/GJ不变，20/40/80段弯曲响应分别约5.999、8.234、16.672毫米，扭转响应约0.05267、0.07965、0.13946弧度。40/80段相对差异约50.61%和42.89%；扭转理论值0.025弧度检查失败。没有事后放宽阈值，也没有通过改变材料、动作或求解条件把失败改写成通过。

外部证据为 `native/v6-analysis.json` 与 `generic-02/controlled-comparison.json`。该历史候选适用于已声明限制的近似演示和继续研究；当时分段无关的工程刚度、定量扭转精度及实物标定未完成。局部诊断不等于上述验收通过，rc1未据此新增外力迭代开关或更换生产算法。

## 0.1.6rc2的修复与复核边界

新隔离安装的软件243项通过；2项外部CAD-FEM fixture本轮未提供而跳过，不沿用历史13/13冒充重跑。Schema1.5仅允许刚体链physics_hz超过4096至16384；旧1.4的范围、读取身份和metadata均不改写，低Hz新链继续1.4。配套USD新增明确TGS外力子步策略和严格重开检查。

配套rc2外力策略也影响低Hz新导出，不是仅Schema1.5的行为。原V6的5秒/2400步几何与结构门槛通过，完整旧/新USD比对仅发现该物理属性新增；原生位姿和速度轨迹确有差异，未将其称为旧默认动态行为或轨迹逐位复现。

原六案已经完整重跑，全部七个已保存NPZ数组逐位重现，原始失败未删除或覆盖。单位链、实际质量/惯量及弹簧长度已独立核对：250mm总长、双5mm端区间的实际串联柔度长度为245mm，故T=1.5e-5Nm、GJ=1.5e-4Nm²时离散参考为0.0245rad，连续参考仍为0.025rad。两者必须分别报告；2%端部差不足解释原大幅过软。

新的原生对照须固定物理输入，先证明时间步/迭代精度，再比较N20/40/80；原5%响应差、10%扭转理论门槛不放宽。原native瞬时速度gate与固定窗pose运动不是同一判据，前者即使失败也须保留。零载同场景保存pose完全不动而返回非零native速度，说明不能只凭一个接口判静止；有载仍需全采样运动包络、局部名义本构残差等补证，不能声称所有瞬时抖动都只是量化误差。

总质量和质心不随N改变，不等于胶囊代理惯量完全相同；本次N20→N80整链Ixx约降5.76%。它影响动力学及有限步长的数值条件，不直接出现在精确零速静态式中。本轮不改质量/惯量、材料或阻尼来促使静态门槛通过。任何限定工况的准静态结果都不能扩展成全动态分段等价、真实多芯线缆标定或任意线缆准确还原。
